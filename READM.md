\# Projeto IMDb



\## Objetivo



Organizar e versionar um conjunto de dados de filmes do IMDb utilizando Git e GitHub.



\## Base de dados



O projeto utiliza o arquivo `tab\_imdb.csv`, que contém informações sobre filmes.



\## Ferramentas utilizadas



\- Git

\- GitHub

\- CSV



\## Organização do projeto



Os arquivos serão organizados em pastas para facilitar a manutenção, a documentação e o versionamento.
