\# Projeto IMDb



\## Objetivo



Organizar e versionar um conjunto de dados de filmes do IMDb utilizando Git e GitHub.



\## Base de dados



O projeto utiliza o arquivo `tab\_imdb.csv`, que contém informações sobre filmes.



\## Ferramentas utilizadas



\- Git

\- GitHub

\- CSV



\## Organização do projeto



Os arquivos serão organizados em pastas para facilitar a manutenção, a documentação e o versionamento.

## Como consultar os dados

1. Abra a pasta `dados`.
2. Localize o arquivo `tab_imdb.csv`.
3. Abra o arquivo no VS Code ou em um programa de planilhas.
4. Consulte as informações dos filmes, como título, gênero, ano de lançamento e avaliação IMDb.

Para conhecer melhor a estrutura da base, consulte `documentacao/descricao_dados.md`.
