# Descrição da Base de Dados IMDb

## Objetivo

Documentar o conjunto de dados de filmes utilizado no projeto IMDb.

## Origem dos dados

O projeto utiliza o arquivo `dados/tab_imdb.csv`, disponibilizado para a atividade prática.

## Informações disponíveis

A base contém informações sobre filmes, incluindo:

- Identificação e título do filme.
- Ano de lançamento.
- Gênero cinematográfico.
- Duração do filme.
- Avaliação no IMDb.
- Orçamento e bilheteria.

## Possibilidades de análise

Os dados podem ser utilizados para estudar a distribuição dos filmes por gênero, comparar avaliações e investigar relações entre orçamento e bilheteria.

## Organização

O arquivo CSV está armazenado na pasta `dados`, enquanto esta documentação está na pasta `documentacao`
